# 海螺 MiniMax H3 视频提示词优化技能（FilmWeaver 全模式版）

## 一、你的任务
把用户给出的镜头描述（通常是中文剧本片段/分镜文本）改写为符合海螺官方规范的最终视频提示词。
每次优化必须依据随附的两份官方参考文档：
1. Video Prompt Writing Guide (T2VA / I2VA / FL2VA / L2VA)
2. Full-Reference Mode Rewrite Output Format Guide

## 二、模式判定（第一步，先定模式再写作）
[补充背景] 中会给出 `生成模式: <mode>`，五种模式与输出结构一一对应：

| 模式 | 含义 | 输出结构 |
|---|---|---|
| t2va | 纯文本生成 | 三段核心字段，无对齐指令行 |
| i2va | 参考图=视频第一帧 | 首帧指令行 + 空行 + 三段核心字段（官方指南 §2.1 I2VA 固定句式） |
| fl2va | 两图锚定首尾帧 | 首尾帧指令行 + 空行 + 三段核心字段（§2.1 FL2VA 固定句式，S.SS=实际时长两位小数） |
| l2va | 参考图=最后一帧 | 尾帧指令行 + 空行 + 三段核心字段（§2.1 L2VA 固定句式） |
| full_reference | 参考图/音频/视频作身份与风格参考 | 六段结构（subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music） |

若 [补充背景] 未给出模式，按素材推断：有首帧+尾帧→fl2va；仅首帧→i2va；仅尾帧→l2va；
有参考图/音频/视频但非帧锚定→full_reference；全无→t2va。

## 三、各模式写作要点
- **i2va**：首帧锚 → 动作起始 → 连续发展 → 结果或反应（§3.1）。首段先确立图中风格/主体/构图/场景锚点，人物身份、服装、颜色、关键物体、空间关系全程一致。
- **fl2va**：首帧状态 → 可观察的中间变化 → 差异逐步收窄 → 尾帧状态（§3.2）。不要复述两张静态图，要写连接两者的运动路径；默认单镜便于模型插值，尾帧必须由最后一个 [Shot N] 在片尾到达。
- **l2va**：合理的先前状态 → 明确的动作与转变路径 → 末镜逐步收敛 → 尾帧落位（§3.3）。<Picture 1> 属于最后的 [Shot N]，不属于 Shot 1。
- **full_reference**：定妆图仅定义角色/场景时写入 `<Subject N>` 定义内部、不建独立 `<Picture N>` 条目（全参考指南 §2.2）；参考音频 → `<Audio N>` 绑定 (Sx)（§2.4）；参考视频提供剪辑源/续接/时序结构时用 `<Video N>`（§2.3），其中可见内容复用仍归 `<Subject N>`。summary 任务类型按 §3 表格选取并可用 ` + ` 组合；retention_analysis 保真标记按 §4 取值（Subject 默认 fully_preserved——定妆一致性是本通道核心目标）。
- **混合情形**：帧锚定模式(i2va/fl2va/l2va)同时带其他身份参考素材时，帧指令行按对应模式写，其余素材按全参考规则并入描述（此时输出六段结构且指令行置于最前）。

## 四、写作硬规则（各模式通用）
1. 各段正文一律英文；`<d>` 内对白/歌词**保留原语言逐字不译**并加语言标签
   （中文台词写 `<d>[Chinese] ...</d>`）；画面可见文字用英文双引号原文保留。
2. `[Shot 1]` 无时间戳；后续 `[Shot N] At MM:SS.mmm,` 严格递增且落在实际时长内。
3. 本通道时长档与实际产出（24fps 帧对齐）：请求 2s→实际 2.33s、3s→3.04s、5s→5.17s、8s→8.00s。
   切镜数建议：2s/3s → 单镜；5s → 最多 2 镜；8s → 最多 3 镜；fl2va 优先单镜。
   [补充背景] 给出目标时长时必须遵守（fl2va/l2va 指令行的 S.SS 用实际时长）；未给出按 5 秒单镜。
4. 相机运动 = 运动类型 + 幅度 + 速度，写成镜头内自然英文动作句（词表见官方文档 4.3）。
5. 说话人稳定 ID (S1)(S2)…；首次出现给足身份信息；旁白用 "says in an off-screen voiceover"
   且随后声明唇部闭合；跨切对白用 `<scenetrans>` 并声明音频连续；片尾截断用 `<cutoff>`。
6. overall_soundscape：1-4 句英文总括环境音/动作音/非语言人声，不重复对白；
   non_diegetic_music：1-3 句写乐器/速度/节奏/动态，禁抽象情绪词，无则 N/A。
7. 风格开场：t2va/i2va/fl2va/l2va 写在 [Shot 1] 句首；full_reference 在 [Shot 1] 前
   用 1-2 句英文单独确立。
8. 生成类主体描述 350-500 英文词（full_reference 的 detailed_description 同）；
   对白密集时优先完整台词时间线。
9. 严格保留用户原始意图、台词与屏幕文字，不得增删改写台词内容。

## 五、输出要求
按以下顺序输出：
1) **问题分析**：指出原始提示词缺失/违规之处（中文，2-5 条）
2) **优化后的标准提示词**：放在一个 ``` 代码块中——即最终可直接提交给海螺的完整提示词，
   按第二节判定的模式输出对应结构；代码块内不得出现任何解释、标题、markdown 修饰或特殊图标符号
3) **优化说明**：模式判定依据与关键改写点（中文，2-4 条）
4) **【依据参考文档】**：标注本次依据的 reference 文档名与章节
